# パーキングメーター地図 / Tokyo Parking Meter Map

東京都内のパーキング・メーター（青）とパーキング・チケット（緑）の設置区間を、地図と一覧で探せるウェブアプリです。

## できること

- 設置区間を**線で地図に表示**（メーター＝青、チケット＝緑。警視庁の地図と同じ色分け）
- **現在地から近い順**に一覧表示（現在地を使わないときは地図の中心から近い順）
- 地名・路線名・住所で検索
- 種類（メーター／チケット）、区市町村、制限時間（40分以内・60分以内・60分超）で絞り込み
- 区間を選ぶと制限時間・料金・時間帯などを表示し、**Googleマップで経路**を開ける
- スマホでは「一覧」「地図」をタブで切り替え。ダークテーマ対応

## データ

区間データは警視庁「[時間制限駐車区間案内地図](https://parking-meter.jp/)」の
[オープンデータ](https://parking-meter.jp/open-data)（GeoJSON）を使います。

**データはまだリポジトリに入っていません。** 入れ方は2通りです。

1. **全員に表示する** — ダウンロードした GeoJSON を `data/zones.geojson` という名前で置いてコミットする
2. **自分の端末だけで見る** — アプリ右上の「データを読み込む」でファイルを選ぶ。端末（IndexedDB）に保存され、次回も表示されます。こちらが `zones.geojson` より優先されます

オープンデータの属性名は決め打ちせず、名前の型で拾っています（`zones.js`）。
「区間名／路線名／名称」「所在地／住所」「種別」「制限時間」「料金」「時間帯／規制時間」「曜日」「車種」などを認識し、
拾えなかった属性も詳細画面の「元データのすべての項目」にそのまま出します。
実データで項目がずれていたら `zones.js` の `PICK` を直してください。

⚠️ 現地の標識・メーターの表示が優先されます。規制時間外や、工事・行事で使えない場合があります。

## 構成

```
index.html   画面
app.js       アプリ本体（Leaflet）
zones.js     GeoJSON をアプリの形にそろえる
styles.css   スタイル（ライト／ダーク対応）
config.js    地図タイル（CARTO）の鍵。空なら OpenStreetMap
data/        zones.geojson を置く場所
vendor/      Leaflet 1.9.4
```

ビルド不要の静的サイトです。`python3 -m http.server 4173` を実行し、http://localhost:4173/ を開きます。
GitHub Pages で公開する場合は、Settings → Pages で main ブランチのルートを選ぶだけです。
